# OpenCredential 1.0.1.1

**Release estable corregido de Desktop. Instalador sin firma Authenticode.** Sustituye al release de GitHub `v1.0.1.0`, retirado a petición del propietario. Se conserva su etiqueta Git y el prerelease anterior; no se mueve una etiqueta publicada ni se reutilizan sus checksums.

## Corrección

El mensaje de bienvenida mostraba `OpenCredential Version: 1.0.0.0` aunque los archivos fueran de una versión posterior. El marcador `%v` utilizaba la identidad de compatibilidad del ensamblado en lugar de la versión del producto.

- `%v` ahora usa `AssemblyInformationalVersion`, con respaldo a la versión de archivo y finalmente a la identidad del ensamblado si faltan esos metadatos.
- En este release el rótulo predeterminado muestra **1.0.1.1**. Se conservan otros marcadores y mensajes personalizados; una versión escrita literalmente por el administrador no se cambia automáticamente.
- La identidad administrada permanece en `1.0.0.0` por compatibilidad. Archivo, producto e instalador están sellados con `1.0.1.1`.
- No se modifica la autenticación, permisos, credenciales, configuración guardada ni protocolos del proveedor nativo.

Incluye las mejoras anteriores: inglés/español, importación XML de idiomas para configuración, ocho plugins adaptados, Acerca de/licencia/créditos, solicitud administrativa adicional opcional (desactivada por defecto), textos nativos bilingües y sincronización offline atómica.

## Instalación

1. Descargar `OpenCredentialInstaller-1.0.1.1-unsigned.exe`, `SHA256SUMS` y `build-info.json` de este release y comprobar los checksums.
2. Mantener una cuenta administrativa local de recuperación y otro proveedor de Windows habilitado; respaldar configuración y datos persistentes.
3. Cerrar la configuración y conexiones RDP y ejecutar el instalador como administrador sobre la carpeta existente. No borrar registro ni cachés para actualizar.
4. La postinstalación debe completar correctamente. Verificar en la siguiente pantalla de acceso el rótulo generado por `%v`; si persiste una pantalla anterior, recrearla/reiniciar Windows cuando corresponda.

## Validación y límites

Una prueba aislada reprodujo el problema antes de corregirlo y pasa con el arreglo: versión publicada, sustituciones múltiples, otros marcadores y textos literales intactos. El formateador se prueba sin crear el servicio ni inicializar configuración real. Se repiten compilación/regresiones Desktop, UI/idiomas, serialización x64/Win32 e instalador.

El propietario confirmó funcionamiento del instalador funcional previo y reportó el defecto de rótulo. No se presenta esa confirmación como una instalación manual del nuevo binario `1.0.1.1`. Se mantienen los límites de aceptación para Windows 10, DPI/NVDA/diseñador, extensiones de terceros, primer login Windows offline integral y cambio de contraseña AdminWeb → Windows.

Distribución solo Desktop; AdminWeb y Docker Hub no cambian. SignPath/firma de confianza siguen pendientes.
