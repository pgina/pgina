# OpenCredential 1.0.1.0-rc.1

**Prerelease para evaluación. El instalador no tiene firma Authenticode.** No es una certificación de producción ni de todas las plataformas compatibles.

## Correcciones principales

- RDP con NLA: descifrado de credenciales protegidas por Windows antes de entregarlas a los plugins; fallo cerrado si no pueden descifrarse.
- PostgreSQL: conservar el tipo de clave al comprobar grupos, evitando errores `integer = text`.
- Bloqueo de cuentas: interpretar correctamente timestamps UTC sin añadir el desfase horario del cliente.
- Logger: reproducción de cola offline con parámetros nulos tipados y origen `offline_cache` conservado.
- Caché offline: protección DPAPI, caducidad, bloqueo local y retirada de usuarios revocados tras sincronizar.
- Instalador: preservar configuración/cachés y comprobar el resultado de postinstalación y el arranque del servicio.
- Dependencias y compilación: migración a log4net 3.5.0 y pruebas reproducibles nativas/SQL/Desktop.

## Instalación y actualización

1. Descargar el instalador y `SHA256SUMS`; comprobar su SHA256 antes de ejecutar.
2. Respaldar configuración/datos y conservar una cuenta administrativa local y el proveedor de contraseña nativo de Windows. Usar primero un equipo piloto o una VM con snapshot.
3. Cerrar la configuración y las conexiones RDP. Ejecutar como administrador; actualizar la carpeta existente sin borrar configuración ni cachés.
4. Si la instalación anterior usaba una carpeta pGina y se reinstala en otra ruta, revisar **Plugin Selection → Search Directories** para apuntar a los plugins realmente instalados. No borrar el registro para solucionar rutas heredadas.
5. Reiniciar el equipo cuando corresponda y comprobar el acceso administrativo alternativo antes de probar la cadena de autenticación.

Requiere .NET Framework 4.8 y Windows 10 21H2 o posterior según la política del instalador. Incluye proveedores nativos x64/Win32 y redistribuibles Visual C++ v14. La versión de archivo es `1.0.1.0`; la versión visible es `1.0.1.0-rc.1`. Se conserva la identidad de ensamblados administrados para no introducir un cambio adicional de binding.

## Validación y límites

Validado en una VM Windows 11 Pro: instalación/actualización, acceso online/offline, clave incorrecta, usuario inactivo, bloqueo/expiración, sesiones y heartbeat, cola offline, RDP con NLA, desinstalación con preservación y reversión por snapshots. La configuración temporal de RDP se retiró al terminar. Las pruebas automatizadas incluyen x64/Win32, SQLite/DPAPI y claves de grupos PostgreSQL integer/bigint/UUID/text.

Esas pruebas funcionales en VM corresponden al código anterior al sellado final de versión. Para esta RC se repitieron compilación y regresiones automatizadas; el instalador con los metadatos `1.0.1.0-rc.1` aún no tiene una nueva instalación manual en VM. Por eso se publica como prerelease.

No se probaron en VM Windows 10 ni todas las extensiones de terceros; la migración de log4net puede requerir recompilarlas. Las CA, SMTP y proxies institucionales requieren validación propia. La reversión de snapshots de laboratorio no certifica una reversión de esquema o datos de producción. El cambio de contraseña desde AdminWeb seguido de login Windows sigue pendiente de aceptación integral.

Este release distribuye **Desktop**. AdminWeb y sus imágenes de Docker Hub se publican por separado; no se modifica la etiqueta `latest` de Docker Hub.
